## CORE

- 新增 `ErrorUtils.PrintError` 和 `ErrorUtils.getErrorDetails`，可直接输出或读取 `ApiException` 的 HTTP 状态码、错误码、请求 ID、响应头、响应正文和原因链。
- 重试判断会遍历包装异常和嵌套 cause，识别超时、DNS、连接等网络原因；HTTP 429、500、502、503、504 默认重试；凭证过期错误码仅在使用可刷新的 SDK 内置 STS 凭证缓存时触发重试。
- AssumeRole、OIDC、SAML 凭证请求统一错误诊断，并校验返回的凭证字段完整；OIDC、SAML 请求改用 OkHttp，代理按 STS URL 的协议选择。
