# Volcengine Java SDK Release

- CloudControl: adds `UpdateResource`, `CreateResource`, `DescribeResourceType`, `ListResources`, `ListTasks`, `DeleteResource`, `GetResource`, `GetTask`, and `ListResourceTypes`.
- CloudMonitor: updates `GetMetricData` and `ListAlertGroup`.
- Insight: updates `ExpertInvokeAPI` and `PullPost`.
- TIS: adds `MigrateDeviceWithoutApproval`.
- I18N OpenAPI: adds `VideoEditorDeleteSubtitle`, `VideoProjectSubtitleDelete`, and `VideoProjectVideoDelete`; updates `VideoEditorDeleteSubtitle`, `VideoEditorGetEmotionTags`, `VideoProjectSerialDubTaskCreate`, and `VideoProjectSerialTaskCreate`.
- VikingDB: updates `CreateVikingdbTask`, `GetVikingdbCollection`, `GetVikingdbIndex`, `GetVikingdbTask`, `ListVikingdbCollection`, `ListVikingdbIndex`, `ListVikingdbTask`, `CreateVikingdbCollection`, `CreateVikingdbIndex`, `MemoryCollectionDelete`, `UpdateVikingdbCollection`, and `UpdateVikingdbIndex`.
